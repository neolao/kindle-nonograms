# API

The server exposes a JSON HTTP API, built with Express (`packages/server/src/app.ts`).

## `GET /api/health`

Liveness check.

**Response — `200 OK`**

```json
{ "status": "ok" }
```

No parameters, no authentication. Used to confirm the server process is up and responding.
