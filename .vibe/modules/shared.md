# Module: shared
**Role:** Domain types and pure helpers shared across the project.
**Files:** `packages/shared/src/index.ts`, `packages/shared/src/puzzle.ts`, `packages/shared/src/clues.ts`, `packages/shared/src/progress.ts`, `packages/shared/src/adapters.ts`, `packages/shared/src/i18n.ts`, `packages/shared/src/thumbnail.ts`, `packages/shared/src/libraryFilters.ts`, `packages/shared/src/solvability.ts`, `packages/shared/src/duplicatePuzzles.ts`
**Exports:** `Puzzle` (interface), `createPuzzle(input): Puzzle`, `ClueRun` (interface), `PuzzleClues` (interface), `computeLineClues(line): ClueRun[]`, `computePuzzleClues(puzzle): PuzzleClues`, `PlayerCellMark` (type), `PuzzleProgress` (interface), `createEmptyProgressGrid(width, height): PlayerCellMark[][]`, `isPuzzleSolved(puzzle, progress): boolean`, `CorrectionResult` (interface: `cells`, `changed`), `correctWrongCells(puzzle, progress): CorrectionResult` — pure; returns a new grid with every cell that doesn't match the solution cleared back to untouched (`null`), sharing its per-cell "is this right" predicate with `isPuzzleSolved` so the two definitions of correctness can never drift apart; an untouched cell is never treated as wrong even where the solution requires a fill — only an actual player mark (a fill or a cross) that doesn't match counts as a mistake to clear, so this never completes a cell the player hasn't attempted, `BooleanGridExport` (interface), `fromBooleanGridExport(id, input): Puzzle`, `Locale` (type), `SUPPORTED_LOCALES`, `DEFAULT_LOCALE`, `TranslationKey` (type), `translate(locale, key): string`, `isSupportedLocale(value): value is Locale`, `buildThumbnail(puzzle, maxDimension): (number | null)[][]` — pure nearest-neighbor downsample of a puzzle's solution grid, capped so neither axis exceeds `maxDimension`; a single scale factor (from the longer axis) applies to both, so the result keeps the solution's true proportions; a puzzle already within the cap is returned unchanged, `SizeBucket` (type), `puzzleSizeBucket(puzzle): SizeBucket` — pure; groups a puzzle into `"small"`/`"medium"`/`"large"` by its total cell count (`width * height`), thresholds at 100 and 400 cells inclusive on the smaller bucket, `isMultiColorPuzzle(puzzle): boolean` — pure; `true` whenever `palette.length > 1`. Both back the library page's size/color filters (see `modules/site.md`, `modules/client.md`). `SolvabilityResult` (type: `{ ok: true } | { ok: false; reason: string }`), `checkSolvability(puzzle): SolvabilityResult` — pure "no guessing required" fairness check: a fixpoint line-solver repeatedly derives forced cells for every row/column from its clue via a dynamic-programming per-line feasibility check (not placement enumeration, so it stays fast on large grids), constrained by whatever earlier passes already forced, until nothing changes; `ok: true` only if every cell ends up determined and matches the puzzle's own solution (see `.vibe/decisions/016-line-solver-fairness-check.md`), `findDuplicatePuzzle(puzzle, existing): Puzzle | undefined` — pure; returns the first puzzle in `existing` whose `width`/`height`/`cells` exactly match `puzzle`'s, ignoring `id`/`name`/`palette`.
**Depends on:** (none)
